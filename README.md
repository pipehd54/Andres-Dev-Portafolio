## ✨ Qué encontrarás

- **Hero lunar interactivo** — luna con parallax al mouse, cielo de estrellas en canvas y estrella fugaz ocasional.
- **Fases lunares** — el modo oscuro/claro funciona como luna llena 🌕 / luna nueva 🌑.
- **Proyectos como expedientes** — caso destacado (Garage API) con ficha técnica, endpoints y decisiones; más dos piezas de apoyo.
- **Terminal simulada + typewriter** con mi stack y estado profesional.
- **Bilingüe ES/EN**, formulario de contacto con fallback a email, y diseño responsive + PWA.

## 🛠️ Tecnologías

| Área | Stack |
| ---- | ----- |
| Maquetación | HTML5 semántico + SEO (Open Graph, Schema.org) |
| Estilos | CSS3 puro (Grid, Flexbox, variables, sin frameworks) |
| Interactividad | JavaScript vanilla (ES6+, canvas, i18n propio) |
| Contacto | Formspree con fallback automático a `mailto` |
| PWA | `manifest.json`, iconos y tema configurados |
| Despliegue | GitHub Pages |
