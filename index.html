Garage API (Backend)

Rol
Backend end-to-end
Estado
Completado · documentado
Núcleo
FastAPI · PostgreSQL

Problema: llevar el control de mantenimiento vehicular (vehículos, servicios, historial) a una API ordenada y segura en vez de registros sueltos. Decisión: FastAPI asíncrono, autenticación JWT con Bcrypt, validación estricta con Pydantic y migraciones versionadas con Alembic.

  • Auth JWT + hash Bcrypt: rutas protegidas y credenciales nunca en claro
  • Contratos Pydantic: errores de datos detectados antes de tocar la BD
  • Alembic: esquema evoluciona con migraciones reversibles
FastAPI async PostgreSQL JWT + Bcrypt Alembic Pydantic
Ver Código en GitHub
api · endpoints
POST /auth/login      → JWT
GET  /vehicles        → lista + filtros
POST /vehicles        → validado con Pydantic
GET  /maintenance/due → próximos servicios
$ alembic upgrade head → esquema al día
